# Codex Account Switch v1.3.0 · Ver 1.3 (19)

## 本次更新

- 折叠和展开的账户卡片均显示下次每周／5 小时窗口重置时间；已经到期的时间标为待刷新。
- 推荐先使用较早重置且仍有额度的账户，同一时间优先剩余额度更多的账户。耗尽账户单独显示预计恢复次序，多个限制窗口均恢复后才算可用；错误、过期及过旧缓存不会被推荐。不会自动切换或消耗重置次数。
- 账户展开区直接显示近 7 天 Token 合计及自动按模型计价的 API 等价估算。范围为含今日的 7 个 UTC 日期，与额度按小时重置的周期不同；明确展示覆盖天数、官方分类／分摊天数、已计价与未计价量。
- 与分析页共用账号隔离缓存，保留失败前的成功数据；卡片固定显示七天，分析页可独立选择 7／30 天。补齐简体中文、繁体中文、英文文档和变更日志，新增界面文案覆盖七种语言。
