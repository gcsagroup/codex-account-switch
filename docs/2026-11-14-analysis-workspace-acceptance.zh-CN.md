## 已实现

- 7／30 天首屏显示期间 Token、轮次、日消耗合计、主要模型；每个来源独立展示覆盖率和状态。统计截至日期与请求成功时间分开。
- 请求检查未知结构、重复日期、非法数值和未读取分页；缺失值不转换为零。失败保留可识别的成功快照，账号／日期不匹配的异步响应不覆盖当前页面。
- 日期与账号确定统计范围；模型、来源、速度只影响支持这些维度的消耗面板。筛选设置按账号保存。
- 每日趋势、模型／来源排行、逐日明细、键盘操作、可展开的全部分类；52 周及累计记录下移并收起。窄窗口首屏指标改为单列。
- 按核验价格和手动速度／上下文情景折算 API 等价值，分类明确、轮次分摊和未计价部分独立显示；未核验组合不套用其他价格。缺少写入 Token 分类时，缓存写入仅展示价格参考。
- 比较不含今天的完整 UTC 日历期间；缺失、失败或单位不同不计算消耗环比，零基期不产生无限增长率。接口无完整性保证，仍注明可能延迟。
- 本机 SQLite 索引只读，按聊天更新时间筛选项目／聊天；不读取聊天正文。创建账号未知可独立筛选，创建账号匹配也不等同整段用量归属；聊天累计 Token 不汇总为期间或云端账号消耗。
- 手动用途标签仅写入应用目录；不接入或冒充官方工作区分类。本机及云端 CSV 分开导出，保留统计口径、单位、缺失、价格与来源说明。
