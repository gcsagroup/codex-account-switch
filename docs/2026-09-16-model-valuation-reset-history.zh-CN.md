# Ver 1.2 自动模型估值与重置历史验收

日期：2026-09-16。版本：1.2.0，构建号 14。固定 App：`dist/Codex Account Switch.app`，Bundle ID：`local.gcsa.codex-account-switch`。

## 交付内容

- 分析默认自动识别账号统计中的模型，逐模型计算并列出普通输入、缓存输入、输出和等价金额；单模型对照保留。
- 官方工作区明细可用时使用报告的 Token 分类；个人账号无此明细时，按同一天模型轮次分摊总 Token，再应用输入／缓存比例，明确标为估算。
- 未知模型、无法分摊的日期及未覆盖 Token 排除于金额之外；标题明确为「已计价部分」。缺失日期不当作零值。
- 价格快照核验于 2026-09-16，来源为[官方价格页](https://developers.openai.com/api/docs/pricing)和 [GPT-5.5 模型页](https://developers.openai.com/api/docs/models/gpt-5.5)。使用标准短上下文价格。
- 账号卡片内展示官方过去 30 天获得／使用重置次数的历史。游标分页完整读取后才替换缓存；按记录 ID 去重，按时间倒序，显示本地时区。不会调用消费重置次数的接口。

## 数据与发布边界

- 本机个人账号的工作区模型 Token 明细接口返回不支持；分类计价分支使用代表性数据测试，尚无真实工作区账号验收。
- 当天轮次占比不等于 Token 占比，分摊估算可能有明显误差。不会把套餐百分比当作 Token，也不会混入缺少可靠账号归属的本地任务日志。
- 标准价估算不含快速模式、长上下文、缓存写入和工具等附加费用，不是账单或节省金额。
- 历史接口只提供过去 30 天。缓存不会补造窗口以前的事件；界面不承诺完整的终身记录。
- GitHub CLI 登录身份只有 READ 权限；发布改由 SSH 身份 GCSA-ToolsTeam 推送标签，仓库 CI 核对固定提交中的已签名原包后创建 Release。CI 成功与 Release 附件回读才算发布完成；App 尚未公证。
